バックテスト結果（ローカル版）

パソコン上の結果フォルダを選ぶと、ブラウザの中だけで読み取って表示します。データは外部に送られません。読み込んだ結果は「結果を含めて保存」で、結果入りのHTMLファイル（スナップショット）として書き出せます。

このページ自体が1つのHTMLファイルです。ファイルそのものをコピーすれば、そのまま別のパソコンでも使えます。「結果を含めて保存」は、読み込んだ結果を埋め込んだスナップショットのファイルを書き出します。

まだフォルダが選ばれていません。bitcoinフォルダ全体、リポジトリ、analysis、チャットのフォルダ、実験フォルダ単体のどれでも選べます。
    読むファイルは summary.csv / results.json / match_summary.csv / audit_checks.json / REPORT.md / README.md と、約定単位カーブのための約定台帳（*_fills.jsonl.gz）、価格表示のための市場データ（market_data の query_results.jsonl.gz）だけです。注文・約定突き合わせ台帳（*_orders.jsonl.gz / *_matches.jsonl.gz など）は読みません。実験フォルダ名に trial を含む結果と、選んだフォルダから結果フォルダまでの名前に smoke を含む結果は対象外です。
